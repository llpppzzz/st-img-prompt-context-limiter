# Image Prompt Context Limit（图像提示词上下文限制）

## 背景（Background）

使用角色扮演预设时，预设通常附带大量 system 消息，要求 AI 扮演旁白或游戏大师（例如“你是一名旁白者，根据以下规则描写场景并扮演角色”“每次回复长度保持在 50 至 150 个单词之间”等）。这些系统消息与图像提示词模板的指令相互冲突，导致生成图片提示词时 AI 不按模板要求的格式返回（如逗号分隔的关键词列表），从而造成生图错误。

## 功能（Features）

- 生成图像提示词时，只向 LLM 发送「最近 N 条聊天消息 + 图像提示词模板」；
- 自动跳过角色卡、世界观，以及旁白 / 游戏大师等预设 system 消息；
- 模板按内容动态识别，自定义模板同样适用；
- 支持“压缩系统消息”：模板被拼进其他系统消息时，只保留模板本身；
- 仅影响 OpenAI 兼容的聊天补全请求；
- 支持简体 / 繁体中文界面。

## 安装

扩展菜单 → 管理扩展 → 安装扩展，粘贴：

```
https://github.com/llpppzzz/st-img-prompt-context-limiter
```

## 使用

打开 **扩展 → 图像生成** 设置面板，在“最小化提示词处理”下方选择**生成提示词时发送的聊天消息数**（默认 1，仅最后一条；设为“全部消息”即关闭）。
