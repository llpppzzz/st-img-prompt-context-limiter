# Image Prompt Context Limit（图像提示词上下文限制）

一个 SillyTavern 扩展，用于裁剪内置 **Stable Diffusion** 扩展生成图像提示词时发送给 LLM 的请求内容（例如“最后一条消息”模式）。

默认情况下，“最后一条消息”模式生成图像提示词时，会把整段聊天历史以及角色卡、场景、世界观、jailbreak 等 system 提示词一起发送给 LLM。本扩展会在运行时改写该请求，只发送**图像提示词模板（system）**和**最近 N 条聊天消息**，让请求更小、更快、更省。

## 功能

- 可配置发送的最近聊天消息条数（1 / 3 / 5 / 10 / 20）
- 图像提示词模板作为最后一条消息发送（聊天消息在前，模板在后）
- 自动跳过角色卡、场景、世界观、jailbreak、示例对话等其他 system 消息
- 安全自动识别：只改写看起来像图像提示词生成的请求，不影响普通聊天
- 支持简体中文 / 繁体中文界面

## 安装

1. 打开 SillyTavern，进入**扩展**（魔法棒菜单）→ **管理扩展**。
2. 切换到 **安装扩展** 标签页。
3. 粘贴 GitHub 仓库地址：

   ```
   https://github.com/llpppzzz/st-img-prompt-context-limiter
   ```

4. 点击**安装**，然后在扩展列表中**启用**该扩展。

## 使用方法

打开**扩展** → **图像生成**（Stable Diffusion 扩展）设置面板，在“最小化提示词处理”下方会自动出现一个新的选项 **生成提示词时发送的聊天消息数**：

- 选择保留最近几条消息（默认 `1（仅最后一条消息）`）
- 设为 **全部消息** 即关闭改写，恢复 SillyTavern 默认行为

选择 `1（仅最后一条消息）` 时，“最后一条消息”模式生成图像提示词的请求体如下：

```json
[
  { "role": "assistant", "content": "<最后一条回复>" },
  { "role": "system", "content": "<图像提示词模板>" }
]
```

## 工作原理

- 监听 `GENERATION_STARTED`：当生成类型为 `quiet` 且提示词文本匹配内置图像提示词模板的特征时，标记为图像提示词请求；
- 监听 `CHAT_COMPLETION_PROMPT_READY`：如果已标记，则将消息数组原地改写为“最近 N 条非 system 消息 + 模板 system 消息”；
- 若“压缩系统消息”把模板与其他系统提示词（如 CoT）拼接成一条 system 消息，插件会用捕获到的提示词重新构造模板内容，只保留模板本身；
- 不修改任何 SillyTavern 内置文件，全部在运行时完成，因此任何实例只需安装本扩展即可生效。

## 限制

- 识别依赖默认提示词模板的文本特征（如 "comma-delimited list"、"portrait" 等）。高度自定义的模板，或自由模式（Free Mode）中纯自定义触发词，可能无法识别。
- 仅对聊天补全（OpenAI 兼容）API 生效，即请求体包含 `messages` 数组的接口。
- 需要内置的 Stable Diffusion 扩展（SillyTavern 默认自带）。
